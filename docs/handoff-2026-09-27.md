## 1. 项目背景

「过稿模拟器」是一款短局职场讽刺网页游戏：玩家是虚构公司「差不多创意部」的设计师，在雕茅经理「感觉很奇怪」式的退回意见、抢功分成和职场插曲中争取过稿。当前需求主题：虚构运动相机品牌「石影」X1 新品的 DTC 独立站上新落地页。

- **技术栈**：React 19 + TypeScript + Vite 7，纯前端，无后端、无登录、无模型密钥，进度存 localStorage
- **仓库**：https://github.com/wekobear/guogao-simulator（main 分支）
- **线上**：https://guogao-simulator.netlify.app（Netlify 站点 ID `dfba021c-d38c-4531-bd28-2c3b494677ba`）
- **本地**：`/Users/vicbear/Documents/z code/过稿模拟器`，`pnpm dev` 开发、`pnpm preview` 预览生产构建

三条不可破坏的原则：

1. 评分与结局由脚本规则决定，AI 只生成/选择评语文案；
2. 规则引擎（`src/game/`）保持纯函数、无浏览器依赖，可被 `tools/verify_spec.py` 复算；
3. `fixtures/golden-paths.json`（六结局固定种子路径）与既有测试是回归底线，改动需谨慎评估。

## 2. 本次迭代做了什么（2026-09-26）

**目标**：把开源原型工具 M3E Canvas（[lnkiai/m3e-canvas](https://github.com/lnkiai/m3e-canvas)，MIT，画 Material 3 Expressive 界面）嵌入游戏，成为「认真模式：亲手画原型」玩法；由 ZCode 编排、codex/agy CLI 协同开发；上线 Netlify。

### 2.1 架构落地方式

- m3e-canvas 以源码形式 vendored 在 `vendor/m3e-canvas/`（fork 点 `42a25a2`，其 .git 已移除，MIT 声明保留，来源记录在 `vendor/README.md`）
- `tools/build-canvas.mjs`：在 vendor 内 `npm ci` → 以 `NEXT_PUBLIC_BASE_PATH=/canvas` 静态构建 → 拷贝 `out/` 到 `public/canvas/`；**产物已存在则跳过，`pnpm build:canvas` 强制重建**
- 游戏侧不 fork 不改造画布代码，桥接完全靠同源 localStorage：iframe 挂载前写入种子文档（`m3e:doc`，画布启动时读这个 key），交稿时直接读回——零 postMessage、零网络请求
- 种子文档（`src/services/canvas.ts`）：桌面首页 1280×800 + 手机竖屏 412×892 双屏、石影品牌橙 `#FF5722`（`BRAND_PRIMARY`）、两条提示部件；**刻意不预置 CTA/主视觉**，让「没画就交稿」的检查自然触发

### 2.2 玩法接入点

- 需求页（BriefView）第四张卡「亲手画原型」：以常规卡片（classic）模板为底稿 + `run.sketchMode` 标记。**没有**把认真模式做成 content 里的第四个模板——`schema.ts` 要求 templates 恰好 3 个、`verify_spec.py` 会遍历所有模板生成金色路径，加模板会破坏两者
- 第一轮工作台（WorkspaceView）显示画布入口，全屏 iframe 覆盖层（`SketchCanvas.tsx`）懒加载；「交稿评审（原型）」触发新动作 `SUBMIT_SKETCH`（`ActionEnvelope.sketch: { doc }` 携带画布文档）
- 引擎内 `analyzeSketch(doc)`（`src/game/prototype.ts`，纯函数、绝不抛异常）按**需求原文逐条检查**：立即购买 CTA / 首屏主视觉 / 手机竖屏 / 页面导航（`action.to` 指向存在的屏）/ 品牌色距离 ≤120 / 部件备注 / >18 部件判超建；输出 findings + 结构完整度 0–100 + `statsDelta`（quality/evidence/scopeDebt，量级与模板校准过）
- 评审页（ReviewView）：原型检查清单 + 雕茅吐槽台词（按首个 finding 选取）+ 《石影X1原型规范》需求文档卡片；S 级过稿换成不情愿的夸奖
- 第二三轮回到原有准备动作流程，`Run.sketch` 冻结快照，旧存档无这些字段按 false/null 兼容
